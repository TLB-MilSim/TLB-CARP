# CLAUDE.md

Guidance for Claude Code sessions in this repository.

Read [CONTRIBUTING.md](CONTRIBUTING.md) first, and follow it: branch, pull request, squash
merge, and the PR description is the commit message. Nobody pushes to `main`.

A session's worth of adjustments is **one** pull request. When a change is asked for and
then refined five times, that is five pushes to the same branch, not five PRs.

Run `python -m unittest discover -s tests` before opening a PR, and say plainly what has
and has not been tested in Arma.
