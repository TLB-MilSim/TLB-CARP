# Publishing the Steam Workshop page

Everything the Workshop item needs lives in this folder.

| File | What it is |
| --- | --- |
| `DESCRIPTION.bbcode` | The page text, with `{{banner-name}}` placeholders where the section banners go |
| `banners/*.png` | Twelve 1000×200 section banners, generated by `tools/gen_banners.py` |
| `workshop-preview.png` | 1280×720 preview image for the item itself |

## The images are already linked

Steam's `[img]` tag needs a URL: images cannot be attached to a description, only linked.
The banners are served straight from this repository, so `DESCRIPTION.bbcode` is
paste-ready as it stands:

    https://raw.githubusercontent.com/TLB-MilSim/TLB-CARP/main/docs/workshop/banners/<name>.png

Two things follow from that. The repository has to stay **public** for the images to load,
and renaming or moving `docs/workshop/banners/` breaks a published page. If you would
rather host them somewhere else, see *Hosting them elsewhere* at the bottom.

## Publishing, start to finish

1. **Regenerate the images** if anything changed:

   ```bash
   python tools/gen_banners.py
   ```

2. **Paste `DESCRIPTION.bbcode`** into the Workshop item. Steam's editor takes BBCode
   directly, and the banner links resolve on their own.

3. **Set the preview image** to `workshop-preview.png`.

4. **Upload the screenshots** from `docs/images/screenshots/` to the item's image gallery —
   the panel, the HUD on a run-in, release stable, and the jump readouts show best.

## Hosting them elsewhere

If you move the banners to Steam's own image host or a CDN, put the URLs in a file, one
`name=url` line per banner (the name is the filename without `.png`), and render a copy
with the links swapped:

```bash
python tools/render_workshop.py --urls build/banner-urls.txt
```

It writes `build/workshop/DESCRIPTION.txt`. It rewrites `{{name}}` placeholders, so a
description that already carries real URLs is passed through untouched — swap the links
back to placeholders first if you want it to do the work.

## Item settings worth getting right

- **Title:** TLB CARP — Computed Air Release Point
- **Tags:** the Arma 3 Workshop tags that fit are *Mod*, *Equipment*, *Multiplayer*,
  *Vehicles* (it ships an item and changes how aircraft drop).
- **Required items:** link CBA_A3 and ACE3 as dependencies so subscribers get them.
- **Change notes:** the release notes for the version you are publishing.

## Keeping it honest

The description quotes measured numbers. If a figure changes in the mod's own records,
change it here too. Every figure traces to a `*Source` note in `calibration/model.json`
or to a flown `USAFDC_CAL_V3` record; the accuracy claims are the flown v1.0.0 drops,
19.3 m and 21.1 m radial, and the guided figures carry the caveat that they were measured
with the steering running on a client rather than a dedicated server.
